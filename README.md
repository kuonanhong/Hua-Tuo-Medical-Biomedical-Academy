# 華佗醫藥生醫學院 · 免費預覽

此儲存庫提供公開的靜態免費教材、互動練習與網站介面。會員專屬教材、帳號、付款、自然語音伺服器及生成式AI由站長的後端提供。

若頁面已設定「AI／會員完整版」，點選即可前往完整網站；模型由該後端以SSH讀取站長的私有模型庫，訪客不需也不會取得GitHub私有庫金鑰。尚未設定後端網址時，免費版AI面板只提供有標示的教材摘要。

開發與更新工具見本站的 huatuo-sync.sh、huatuo-private-ai.sh；站長應使用自己持有的完整來源包作為同步來源，公開版不包含完整會員教材或站長私密設定。模型、私鑰、會員資料庫與.env不得放入公開網站。

本網站內容供醫學教育與非侵入虛擬練習；來源、覆蓋與審定情形列於各頁。第三方資料與模型各依其授權；網站程式授權見LICENSES.md。
