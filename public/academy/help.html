1. 開始使用 · Getting started

  1. 雙擊最外層 index.html（或開啟 public/academy/index.html）即可離線瀏覽全部 2,400+ 門課程；不需安裝任何軟體。
  2. 首頁背景會輪流播放每門課程專屬的圖示（每一門都不同）；按「免費試學」可直接開始任一門課的第一節。
  3. 「探索課程」可依學院（西醫外科、西醫內科、中醫、生醫基因、AI 與諾貝爾）、科別、種類（手術／技術／穴位／方劑／獎項…）、級別與是否免費篩選；上方搜尋列支援中文、英文、穴位代碼（如 LI4）、方劑名與手術名。
  4. 課程頁左側為章節（節），右側為步驟：目標 → 操作 → 觀察 → 失敗模式 → 驗收 → 知識點 → 測驗。完成步驟會記錄在「我的進度」。

Double-click index.html to browse all 2,400+ courses offline. The home background rotates through every course's own icon. Use “Explore courses” to filter by faculty, department, kind, tier and free status; the search box understands Chinese, English, point codes (LI4), formula and operation names. Each course page lists sections on the left and steps on the right (objective → action → observation → failure modes → acceptance → knowledge → quiz).

2. 基本級與實習級 · Basic and internship tiers

  • 基本級（跟師傅學）：逐步拆解每一項專業工藝——手術流程（如 DBS、CABG、全膝置換）、檢查技術、穴位、方劑、諾貝爾研究方法——每一步都有驗收標準與測驗。
  • 實習級（面對病人）：「實習門診」提供虛擬病人。中醫：望（舌象）、聞、問（主訴）、切（脈象訓練器，可用滑桿模擬舉按尋）、辨證、治法處方並評分；西醫：量血壓（按住充氣、Korotkoff 音）、測血糖、生命徵象、心電圖判讀、檢驗判讀與 SOAP 病歷。
  • 每門課的第一節免費；其餘章節與實習級需要學習通行證（見第 5 節）。

Basic tier: learn each craft step by step from the master. Internship tier: virtual patients — TCM inspection, listening, inquiry, pulse (with a pressure slider) and tongue trainers, pattern differentiation and scored prescriptions; Western BP cuff, glucose, vitals, ECG rhythms, labs and SOAP notes. The first section of every course is free; the remaining sections and the internship tier need a learning pass.

3. 中醫圖庫 · TCM library

「中醫圖庫」集中整理 361 個正經穴位＋經外奇穴（經絡、定位、主治、針法）、255 味常用中藥（性味歸經、功效、用量、注意）、176 首方劑（出處、組成、主治、加減）、經典著作（《黃帝內經》、《傷寒論》、《金匱要略》、《溫病條辨》、《針灸甲乙經》…）與推拿／泰式按摩手法。每個項目都連到對應課程。影片延伸學習可從課程「來源」區連到「子子中醫」等公開頻道。

The TCM library gathers 361 classical acupoints plus extra points, 255 herbs, 176 formulas, the classics and manual-therapy techniques, each linked to its course.

4. 帳號與驗證 · Accounts and verification

  1. 按右上角「訪客學徒」→ 註冊。必填四項：帳號、密碼（≥10 字元含字母與數字）、信箱、手機號碼（含國碼，如 +886912345678）。
  2. 伺服器模式會寄送信箱驗證碼與簡訊驗證碼，兩組都輸入正確才完成註冊並自動登入。登入可用帳號或信箱。
  3. 離線（雙擊 index.html）或純靜態網頁（GitHub Pages）無法寄送驗證碼，只會建立「本機學習檔案」，進度存在瀏覽器；更換裝置前請在「我的進度」匯出 JSON。

Registration needs username, password, e-mail and mobile number. In server mode you receive an e-mail code and an SMS code; both are required. Offline/static editions create a browser-local profile instead.

5. 付費與幣別 · Learning pass and currency

  • 定價以新台幣計：NT$299／30 天、NT$2,490／365 天，一次付款不自動續扣。
  • 顯示幣別依瀏覽器語言的地區（例如 ja-JP → JPY、de-DE → EUR）或時區判斷，並以最新匯率換算；可在右上角幣別選單手動切換。
  • 付款方式：信用卡（Stripe Checkout，含 3-D Secure 驗證）、綠界 ECPay（台灣）、或轉帳至站長郵局帳戶（局號 0101034、帳號 0187821）後填寫轉帳時間與帳號末五碼，站長核對後開通。
  • 卡號只在金流商頁面輸入；伺服器收到簽章通知並主動查單確認後才開通權限。

Prices are set in TWD and converted to your locale's currency using current exchange rates (changeable at the top right). Pay by card through Stripe (3-D Secure) or ECPay, or by transfer to the operator's post-office account followed by a claim form. Access opens only after the server verifies the gateway's signed notification.

6. 語音與語系 · Voice and language

項目行為
介面語言首次開啟依瀏覽器語言偏好（navigator.languages）自動選擇，36 種語言可手動切換並記住。
語音朗讀語系預設跟隨目前介面語言（即觀看者的瀏覽器語言），不是依 GPS 或 IP 位置；可在「個人桌面」改為固定某語系。
語音性別／音高／語速／風格由瀏覽器提供的語音清單選擇；可選男聲、女聲、專業／親切／精簡風格，並試聽。
課程內容語言中文與英文為原著核心；其他語言的課程內容需伺服器設定 AI 翻譯路線才會自動翻譯，否則保留原文。

Interface language follows the browser's language preference and can be changed. Narration language follows the interface language by default (not GPS/IP) and can be pinned. Voice gender, pitch, rate and style come from the browser's voice list.

7. 個人桌面 · Personal workspace

按 ⚙ 可設定：淺色／深色／跟隨系統、舒適／緊湊版面、側欄左右、字體大小、主色、首頁圖示動畫、語言、幣別、語音。每位會員（或本機檔案）各自記住設定，並可匯出／匯入。

⚙ opens theme (light/dark/system), layout density, sidebar side, font size, accent colour, home icon animation, language, currency and voice settings, remembered per member.

8. AI 師傅 · AI mentor

「✳ AI 師傅」以目前課程、相關課程步驟與站長索引的本地教材為依據回答學徒問題。伺服器需設定一條生成式 AI 路線（本機 llama.cpp／Ollama、OpenAI 相容服務、OpenAI、Anthropic 或 Gemini；見 docs/AI_ROUTES_ZH.md）。雲端路線需勾選同意後才會送出問題。未設定時只回傳教材摘要並標示「非生成式」。

The mentor answers from the current course, related curriculum steps and the operator's indexed documents through a configured generative route (local llama.cpp/Ollama, OpenAI-compatible, OpenAI, Anthropic or Gemini). Cloud routes require consent; without a route the panel returns labelled curriculum summaries.

9. 離線、安裝與更新 · Offline, install and update

  • 手機／平板：以瀏覽器開啟網址後「加入主畫面」，即為 PWA；HTTPS 部署時會快取課程以供離線閱讀。
  • 電腦：bash run-local.sh（macOS／Linux）、run-local.bat（Windows）啟動含帳號、付款與 AI 的伺服器；Python 3.10+ 即可，不需其他套件。
  • 站長更新：bash update-and-upload.sh --ssh user@host:/srv/huatuo 會把本地更新的程式、新增的教材與模型權重上傳並可重啟遠端服務。

Add to home screen for a PWA on phones and tablets. run-local.sh / run-local.bat start the full server (Python 3.10+, no packages). update-and-upload.sh uploads local code updates, new documents and model weights.

10. 常見問題 · FAQ

看不到語音選項？ 部分瀏覽器（尤其 iOS Safari）需先與頁面互動後才載入語音清單；再按一次「試聽」。

圖示為何不是網路圖庫？ 全部 2,420 個圖示是本專案原創的離線 SVG 圖形系統，建置時驗證每一門課程的圖示描述都不重複，離線也能顯示。

內容可以當臨床依據嗎？ 不可以。本站提供醫學教育資訊，不能取代個別診斷與治療；手術、針灸與處方須在合格醫師監督下學習與執行。

Voices may load only after you interact with the page (iOS Safari). All icons are an original offline SVG system verified unique at build time. The content is educational and never a substitute for individual diagnosis or treatment.
